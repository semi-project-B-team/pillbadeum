# ProfileTag

본인 · 가족 이름 앞에 프로필 색 점을 붙인 작은 태그로, 이 약 · 일정이 누구 것인지 보여 줄 때 쓴다.

## 쓰는 법

`<span class="mt-ptag mt-ptag--p2">엄마</span>`

소비하는 쪽이 정하는 것: 이름(본인은 닉네임, 가족은 관계 이름), 프로필 순서에 맞는 색 번호.

## 색

| 클래스 | 면 / 점 / 글자 |
| --- | --- |
| `mt-ptag` (= `--p1`) | `profile-1-weak` / `profile-1` / `profile-1-ink` |
| `mt-ptag--p2` | `profile-2-weak` / `profile-2` / `profile-2-ink` |
| `mt-ptag--p3` | `profile-3-weak` / `profile-3` / `profile-3-ink` |

- 높이 28px, 좌우 10px, 14px 700, 점 10px, 모서리 `radius-full`.
- 개수를 붙여도 된다: "엄마 3개".

## 쓰는 자리 (목업)

홈 오늘 먹을 약 · 할 일, 이 시각 약(NTF-02), 약 목록 · 약 상세 머리, 사진 등록 화면 머리("약 목록에 넣어요" 앞), 일정 수정의 프로필 칸. 헤더 "관리할 사람"과 달력 막대도 같은 색을 쓴다.

## 지킬 것

- 같은 사람은 모든 화면에서 같은 색이다. 색은 프로필 순서로 정하고 화면마다 바꾸지 않는다.
- 프로필이 넷 이상이면 색을 다시 돌려 쓰되 이름이 항상 함께 보이게 한다.
