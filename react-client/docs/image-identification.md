## 알약 이미지 식별



### API 사용



- 알약 사진 식별에는 `POST /api/images/pill-photo/identify`를 사용한다.
- `Content-Type: multipart/form-data`로 전송하고, 업로드 필드명은 `images`로 한다.
- 앞면과 뒷면 사진을 최대 2장 올릴 수 있다. 가능한 경우 첫 번째 파일은 앞면, 두 번째 파일은 뒷면 순서로 보낸다.
- 이 API는 로그인 없이 사용할 수 없다. 
- 요청 크기·파일 형식 제한과 에러 응답은 서버 설정에 맞춘다. 응답 오류의 내부 상세 정보를 사용자 화면에 그대로 노출하지 않는다.
-처방전 또는 약봉투 사진 식별에는 `POST /api/profiles/{profileId}/photo-identifications`를 사용한다.



### 응답 처리



- 응답의 `extracted`는 이미지에서 읽은 단서(식별정보)이고, `candidates`는 공공데이터 낱알식별정보를 검색해 점수순으로 정렬한 후보 목록이다.
- extracted·candidates·similarityScore 설명은 알약 사진 식별 응답에 대한 내용이다.
- `similarityScore`는 후보 간 정렬 참고값이지, 검증된 확률이나 확정 식별 결과로 표시하지 않는다.
- 후보가 없거나 일치하는 약을 찾지 못하면 정확한 약으로 단정하지 말고 재촬영 또는 이름 검색을 안내한다.
- 사용자가 후보를 선택하기 전에는 식별 결과를 복용 약으로 등록하지 않는다.
- 후보 표시에는 품목명, 제조사, 앞·뒤 각인, 모양, 색상, 제품 이미지 등 응답 필드를 활용한다. 없는 값은 임의로 추측하거나 만들어내지 않는다.



### 사진 UX



- 앞면과 뒷면을 각각 촬영하거나 선택할 수 있게 하고, 업로드 전에 미리보기를 제공한다.
- 알약 사진 식별에는 앞면과 뒷면 사진이 필요하지만 텍스트를 식별할 수 있는 이미지라면 둘 중 하나만 업로드 하는 것을 허용한다. 
- 알약 사진 식별에서 앞면과 뒷면의 사진 순서가 바뀌어도 허용한다.
- 알약 하나가 화면에 크게 보이도록 안내하고, 흔들림·초점 흐림·강한 반사·어두운 사진은 다시 촬영하도록 안내한다.
- 촬영 순서가 앞면/뒷면과 일치하는지 확인할 수 있도록 사진별 라벨을 제공한다.
- 처리 중에는 중복 제출을 막고 진행 상태를 보여준다. 취소·화면 이탈 시 업로드 상태를 안전하게 초기화한다.



### 안전과 개인정보



- 이미지 식별은 후보 제안 기능이며, 의약품 복용 여부나 복용량을 결정하는 진단 기능으로 표현하지 않는다.
- 응답의 효능·복용법 정보가 포함되어도 이미지 식별 후보와 혼동해 복용 지시로 제시하지 않는다.
- 이미지에 개인정보나 처방전이 포함되지 않도록 사용자에게 안내한다.
- 토큰, API 키, 개인정보, 이미지 원문을 로그·분석 이벤트·오류 리포트에 기록하지 않는다.
