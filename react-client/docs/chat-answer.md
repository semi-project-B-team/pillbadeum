# CHT-02 답변 표시

- 적용 범위는 기존 채팅 답변 말풍선임. 진입·이탈·전송·저장·근거 접힘과 API는 유지함.
- 읽기 순서는 답변 본문 → 기존 DUR 카드 → 근거 보기 → 답변 시각임. API의 content·durNotice를 그대로 사용함.
- 본문은 문단·줄바꿈·굵게·글머리·번호 목록과 마크다운 표를 표시함. 표는 제목 행과 구분선이 있을 때만 해석하며 나머지 기호는 글자로 표시함.
- 표의 셀에도 기존 굵게 처리를 사용함. HTML을 실행하지 않으며 링크·스크립트를 만들지 않음. 빈 셀은 보존함.
- 긴 내용은 셀 안에서 줄바꿈함. 여러 열로 화면 폭을 넘는 표는 표 영역만 가로 스크롤함. 채팅 입력창·근거 영역·바깥 페이지의 너비를 밀지 않음.
- 색·선·간격·서체는 design/README.md·pillbadeum-tokens.json의 기존 말풍선 토큰을 사용함. 새 토큰·화면·패키지는 추가하지 않음.
- 확인 폭은390px·1280px임. 정상 표·긴 표·여러 줄 본문·굵게/목록 혼합·손상된 표·HTML 글자·근거 접힘·새로고침을 검증함.
- 변경 근거는2026-10-24 사용자의 표 렌더링 직접 수정 승인임. 화면 검증 캡처는 QA 리포트에 연결함.
