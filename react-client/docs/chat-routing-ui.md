# 조회 목적·저장 접근성 화면 정의

- 사용자2026-10-24의6개 구현 지시를 반영함. 기존 API·요청/응답·오류 코드·DB 구조·@@SOURCES@@의6필드/4타입을 유지함.
- MED-03 일반 검색은 선택한 약/대상과 저장·다른 약 고르기를 하단 공통 저장 줄에 둠. 선택 전/이미 등록/저장 중 상태와 실패 시 선택 보존을 유지함. 처방전 이름 보완 검색은 후보의 이 약으로 고르기→결과 복귀를 유지함.
- IMG-04·05는 기존 PhotoSaveBar를 재사용함. 주 행동은 화면 하단에 접근 가능하게 두고 긴 저장 범위 도움말은 본문에 보존함. 후보0/과다/미선택 상태의 저장을 활성화하지 않음.
- MED-03·04의 공식 효능/용법/주의는 제목이 보이는 접기·펼치기로 원문 전체를 보존함. 좁은 MED-04에서는 내 복용정보·수정/일정 보기를 공식 설명보다 먼저 둠. PC 두 영역과 삭제 확인은 유지함.
- CHT-02의 근거 보기 혼합 총계를 제거함. 확인된 공식 자료·내 복용 기록·미확인 자료를 구분함. ok=false의 구체 원인을 추정하지 않으며 전체 미확인·허가 취하·실제 DUR 경고를 유지함.
- CHT-02의 DUR 고정 안내·항목은 기존 카드에 한 번 표시하며 본문에 다시 붙이지 않음. 정상 무경고 결과는 DUR/금기/병용을 물을 때만 안내함. 실제 경고·부분/실패 결과는 유지하고 첫 답변에서 카드가 생략되면 본문에 보존함. API·DB·프런트 구현 변경 없이 서버 표시 정책만 보완함. 추가 모바일 QA는 제외함.
- 메뉴/제목/답변 접근성 표시는 약봉이로 맞춤. 서비스명 필받음·/chat 주소·서버 명세 이름은 유지함.
- 기존 토큰/라이브러리를 사용함. 저장 줄에 가리는 마지막 본문/모바일 키보드·저장 중 중복·실패·선택 유지·긴 문서/후보·키보드 포커스·과거 근거/새로고침을 실제 PC/모바일에서 확인함.
- npm run lint/build와 실제 이름 검색/처방전/낱알 결과·채팅 회귀를 각각 검증함. [고정 준비 근거](https://github.com/kodonghui/pillboot-design/blob/9effb3ef4fac90576e09111e4236278b7bb77c46/09-development/reviews/2026-10-24-ui-actions-and-retrieval-routing.md)를 연결함.
